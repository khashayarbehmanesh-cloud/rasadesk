# آرم رسا

فایل‌های زیر را اینجا بگذارید تا جایگزین آیکون‌های RustDesk شوند (نام‌ها دقیقاً همین‌ها):

| فایل | اندازه |
|---|---|
| `icon.ico` | آیکون ویندوز (چندلایه 16/32/48/256) |
| `icon.png` | 1024×1024 یا 512×512 |
| `32x32.png`, `64x64.png`, `128x128.png`, `128x128@2x.png` | همان اندازه‌ها |
| `icon.svg` | لوگوی برداری (اختیاری) |

هر فایلی که نباشد رد می‌شود. نام و آرم خود RustDesk نباید در محصول نهایی بماند.
